# momo-shop-work

Mocking momoshop — a frontend-only (mock data, no real API calls) rebuild of the momo e-commerce home page and goods detail page.

> Status: **work in progress.** Architecture docs, ADRs and tradeoffs land in `docs/` and this README as the work proceeds — see the commit history for the step-by-step plan.

## Stack

Nx (pnpm workspaces) · React 19 · TypeScript (strict) · Vite · Vitest

## Getting started

```bash
pnpm install
```
