# Design

## Context

- Human 附了真站與我們的截圖，指出官方優惠這一段長得不像。
- 以 1440 × 900 的視窗讀真站（2026-09-20）的 DOM 量測。目標截圖 `docs/pictures/06-official-deals.png` 是更早的版本（這一段是黃底）；這次照 Human 的要求以**真站**為準。
- 首頁由版位資料驅動（`docs/architecture.md` §6）：`HomeSection` 是 union，`SectionRenderer` 依 `type` 找元件；頁面外框 `PageSurface` 原本用 `gap-4` 在每個區塊之間留 16px。

量測結果（真站 → 我們，修改後）：

| 項目                   | 真站                                                                  | 我們         |
| ---------------------- | --------------------------------------------------------------------- | ------------ |
| 官方優惠圖示（輪播）   | 高 192.5：圖上方 16、圖 148.5、圖下方 28（圓點在圖下 12px）           | 同           |
| 捷徑＋熱搜             | 高 136，左右兩欄各 610                                                | 同           |
| 捷徑                   | 5 欄各 118，圖 98 × 98，第一個在 x = 20                               | 同           |
| 分隔線                 | x = 610，1px `#d1d5db`                                                | 同           |
| 熱搜排行               | 3 × 3，一項 188.3 × 32，間距 6，上下 14、左右 16                      | 同           |
| 名次圓圈               | 20 × 20，12px 粗體白字；`#ff4343` / `#ff6a00` / `#ffc800` / `#b3b3b3` | 同           |
| 新上榜                 | 名次圓圈右下 6 × 6 的 `#ef4444` 圓點                                  | 同           |
| 關鍵字                 | 13 / 18px `#000`，過長以「…」截斷                                     | 同           |
| 熱度                   | 13px `#9ca3af`                                                        | 13px `#999`  |
| 上升                   | 10 × 16 的箭頭 `#dd2222`                                              | 同           |

整頁來看，真站只有這些區塊下方有 16px 的間隔：詐騙提醒、momo 店取、信用卡加碼、限時搶購，以及一個目標截圖與我們都沒有的區塊（`bt_7_703_04`）。

## Goals / Non-Goals

**Goals:**

- 官方優惠三塊的版面、尺寸與間隔和真站一致（上表）。
- 熱搜的名次、上升、新上榜，螢幕閱讀器也讀得到。
- 區塊之間的間隔由版位資料決定，不寫死在元件裡。

**Non-Goals:** 見 proposal 的 Non-goals（灰色膠囊、熱搜可點或即時更新、詐騙提醒的內部版面）。

## Decisions

### 1. 間隔是版位的屬性：`gapAfter`

**選擇**：`HomeSection` 的共同欄位多一個選填的 `gapAfter`。`SectionRenderer` 在標示的區塊後面放一個 16px、`aria-hidden` 的空元素（透出頁面的灰底，就是那條灰色間隔）；`PageSurface` 拿掉 `gap-4`。

**理由**：同一種區塊有時有間隔、有時沒有 —— momo 店取與今日暢銷榜都是 `product-rail`，只有前者下方有。所以間隔不是元件的屬性，而是「營運怎麼排版位」；放在版位資料裡，改版位就不用改程式。

**放棄的方案**：

- **在各區塊元件加 `margin-bottom`**：做不到上面「同一種元件、不同結果」。
- **反過來標示「緊貼」**：15 個區塊只有 4 個下方有間隔，預設值應該是多數的情況。
- **用 margin 而不是元素**：不是每個區塊都用 `SectionFrame`（限時搶購在另一個 package），margin 只能加在錯誤邊界這類與版面無關的地方；獨立的元素也好在測試裡找（`data-section-gap`）。

### 2. 熱搜放在捷徑列的資料裡

**選擇**：`ShortcutBarSection` 多一個選填的 `hotSearches: HotSearch[]`；名次就是陣列順序，不另存欄位。

**理由**：真站的捷徑與熱搜是同一個區塊（一個 `grid-cols-2`，中間一條線）。拆成兩個版位，「兩欄各半」的版面就得靠外層組合。名次不存欄位，就不會出現兩個第 1 名。

**放棄的方案**：新增 `hot-search` 版位。要新的 section type 與 registry 項目，換來的只是能把熱搜放到別處 —— 真站沒有這樣用。

**代價**：沒有熱搜時，左欄仍只佔一半寬。目前的版位資料一定有熱搜。

### 3. 熱搜的內容照目標截圖、不可點

內容照目標截圖（第 5、8 名在截圖上被截斷，以真站當天的完整關鍵字補上）。真站當天的熱搜已經不同，熱搜本來就會變，所以不追真站的內容，只追版面。搜尋頁不在範圍內，所以熱搜不是連結。

### 4. 上升、新上榜：圖形加文字

上升是紅色箭頭（SVG），新上榜是名次圓圈右下的紅點，兩者都 `aria-hidden`，旁邊各加一段 `sr-only` 的「上升」「新上榜」。真站只有圖形，螢幕閱讀器讀不到。

### 5. 輪播的底部留白：依「最後一列是不是圓點」

**原本**：有標題的區塊底部留 4px（圓點那一列本身有留白），沒有標題的留 16px。

**量到的**：真站所有輪播，不論有沒有標題，圖的下方都是 28px。沒有標題的輪播（官方優惠圖示、品牌折扣、信用卡加碼）因此多了 12px。

**選擇**：`SectionFrame` 的 `endsWithDots`，由輪播與商品列傳入；判斷依據從「有沒有標題」改成「最後一列是不是圓點」，這才是留白不同的原因。

### 6. Token

新增名次圓圈的四個顏色、新上榜的紅點、關鍵字、分隔線與 12px 字級（兩層 token，見 `docs/design-tokens.md`）。

兩處刻意沿用既有的 token：

- **熱度的灰**：真站 `#9ca3af`，我們用既有的 `ink-muted`（`#999`）。差別很小，不值得多一個幾乎相同的灰。
- **熱搜的圓角**：真站 20px，我們用既有的 `rounded-pill`（22px）。高度 32px 時兩者都畫成完整的半圓，看起來相同。

## Risks / Trade-offs

- **真站會改版**：這次以 2026-09-20 的真站為準；目標截圖是更早的版本（黃底、白色膠囊）。兩者不同時，以 Human 指定的為準。
- **`gapAfter` 是布林值**：真站的間隔都是 16px。之後若出現不同高度的間隔，要改成數值。
- **圖示標題的膠囊看不到**：素材是目標截圖那一版（見 proposal）。
